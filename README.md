# Lavender Dream Moderator Bot

Отдельный Telegram-бот для анкет новых участников и модерации Lavender Dream. Использует отдельную SQLite-базу и не подключается к базе основного Lavender Dream.

> Проект переносится из последней версии архива. Не добавляйте `.env`, токены или локальную базу данных в Git.
